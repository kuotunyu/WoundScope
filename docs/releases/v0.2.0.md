# WoundScope v0.2.0

WoundScope `v0.2.0` 是完成 M7 與 repository closeout hardening 的軟體版本。它保留
`v0.1.0` 已凍結的正式實驗結果與 provenance，不重跑 training，也不改變 scientific
protocol、locked official-validation metrics 或 medical scope。

## 本次更新

- 完成 M7 Hugging Face Space deterministic code-only candidate、exact inventory、
  non-mutating import、CPU Docker 與 clean-clone reproduction gates。
- 新增 repository-level privacy audit，讓本機、pytest、GitHub Actions 與 release gate
  共用同一套 Git index blob contract；即使使用 `git add --force` 或工作目錄內容與 staged
  blob 不同，也會拒絕 non-regular entries、環境檔、private artifact directories、
  image-level／tabular artifacts、TensorBoard events、model artifacts、raster images、
  高可信度 secrets 與本機 home paths，且不回顯 private content。
- GitHub Actions 同時驗證 Python 3.11／3.12，並在 Python 3.12 執行 wheel／sdist build
  smoke test；branch protection 所要求的 `synthetic-gates` 只有在兩個 job 都成功時才通過。
- Release gate 要求在發布前由 GitHub API 讀回確認 Dependabot alerts 與 Python CodeQL；
  不啟用 bot 自動提交，Contributors policy 仍只有 `kuotunyu`。
- 同步 README、PROJECT_PLAN、PROGRESS、CITATION 與 package version metadata。

## 實驗結果與 provenance

正式 privacy-safe machine-readable results 仍由 `v0.1.0` Release 提供；其 training
source、aggregate metrics、safe result ZIP checksum 與既有 tag 均保持不變。`v0.2.0`
不重新包裝或宣稱新的模型結果。

## 權限與 artifact 界線

Model-backed Hugging Face Space 維持 `PERMISSION_PENDING`。本 Release 不包含
FUSeg images／masks、image-level results、private galleries、model weights 或
ONNX binaries，也不建立 model repository 或 live model deployment。

- 不宣稱 official-test metrics；官方未公開 test masks。
- 不宣稱 patient-wise split；資料沒有 patient ID。
- 不宣稱 臨床效能、診斷、嚴重度、預後或治療能力。

## 授權

WoundScope 自有程式碼使用 Apache-2.0。FUSeg data、weights 與衍生 image-level
artifacts 不受此 code license 涵蓋，也不隨本 Release 散布。
