# WoundScope v0.1.0

WoundScope `v0.1.0` 是可重現、可測試、可部署的足部潰瘍影像 segmentation
research pipeline 首個正式公開版本。人讀文件與操作說明以正體中文（`zh-TW`）為主，
technical proper nouns 保留原文。

## 內容

- Pinned FUSeg data integrity／duplicate audit 與 `exclude_train` mitigation。
- EfficientNet-B0 U-Net baseline 與 SegFormer-B0 advanced model。
- Resumable Colab quick／full／multi-seed staged pipeline。
- Locked official-validation evaluation、dev-only calibration、TTA confidence 與 2,000 次
  image-cluster bootstrap。
- ONNX parity diagnostics、CPU benchmark、Gradio interface、Docker 與 synthetic GitHub CI。
- Public Colab `v0.1.0` source fallback 與 private Drive immutable ZIP／resume workflow。
